# axon MUS (엑셀) — 기능 요약 & 출처

화폐단위표본추출(MUS / PPS)을 엑셀에서 수행하는 감사용 도구. **설치 의존성 0** — 엑셀만 있으면
동작한다(별도 프로그램·인터넷·라이브러리 불필요). 모든 수치 계산은 로컬에서 결정론으로 처리된다.

---

## 1. 무엇을 하는 도구인가

거래 데이터에서 **금액이 큰 항목일수록 뽑힐 확률이 높은** 표본을 통계적으로 추출하고(ISA 530식 MUS),
감사인이 검토 결과를 입력하면 **모집단 전체의 왜곡표시를 추정·평가**해 "이 모집단을 받아들여도
되는가"까지 판정한다. 실행 이력은 감사추적용으로 자동 기록된다.

## 2. 핵심 기능

| 구분 | 기능 |
|---|---|
| **표본추출** | Key Item(표본간격 이상 고액 = 전수검사) + 잔여 모집단 시드 기반 **체계적 PPS 추출** |
| **재현성** | 같은 (범위·PM·신뢰수준·시드) = 항상 같은 표본. 시드·랜덤시작점 기록 → 재수행 시 동일 표본 재현 |
| **자기문서화 조서** | 결과 시트 A1 셀의 **노트(메모)** 에 파라미터·표본 요약 자동 첨부(천단위 콤마) |
| **평가(Extrapolation)** | 오염률(Tainting)·추정왜곡(Projected)·기본정밀도·**상한오차(UEL)**·수용/기각 판정 |
| **증분 신뢰계수** | 발견오류를 오염률 내림차순 정렬 후 증분계수 `R(j)-R(j-1)` 차등 적용 → UEL 정밀화 |
| **신뢰계수 산출** | R(k)를 **순수 VBA 포아송 역산**으로 계산(워크시트 함수·외부 의존 0). AICPA 표와 일치 |
| **감사추적 로그** | 실행마다 `MUS_Log` 시트에 1행 누적 — 누가·언제·어떤 파라미터로·결과 요약(통합문서 전체 대장) |
| **사용 편의** | 실행 시 **항목명 입력 → 시트명 `MUS_<항목>`**, 탭 색 구분. `.xlam` 추가기능 버튼(표본추출/평가/도움말) |
| **내장 도움말** | `MUS 도움말` 버튼 → 단계별 상세 사용법 시트 자동 생성(인쇄해 조서 첨부 가능) |
| **국제화** | 한글판(CP949)·영어판(ASCII) 동일 기능 제공 |

## 3. 결과 시트 구성

- **표본 표**: 원본 열 + `유형`(고액항목/PPS표본) · `장부가` · `감사가`(감사인 입력) · `오염률` · `추정왜곡`
- **A1 노트(요약)**: 모집단 건수/총액 · PM · 신뢰수준 · 신뢰계수 R0 · 표본간격 · 시드/랜덤시작점 ·
  표본 수 · 기본정밀도 · **추정왜곡 · 증분허용오차 · 상한오차(UEL) · 판정**

## 4. 사용 흐름

1. `MUS 표본추출` → 범위·금액열·PM·신뢰수준·시드·항목명 입력 → 표본 시트 + 로그 생성
2. 표본 항목 검토 후 **`감사가`** 열에 실제 금액 입력
3. `MUS 평가` → 노트의 UEL·판정 갱신 (`UEL ≤ PM` 이면 수용 가능)

## 5. 인용·근거 (무엇을 참고해 만들었나)

### 감사 표준
- **ISA 530 (감사 표본추출)** — 표본추출 + **왜곡표시 추정·평가** 요구사항. 도구의 전체 워크플로 근거.
- **AICPA Audit Sampling Guide (Table C-3, 신뢰계수표)** — 신뢰계수 R(k) 및 **증분 신뢰계수 평가법**.

### 적용한 핵심 공식
- 신뢰계수 `R = -ln(1 - 신뢰수준)`(0오류 포아송), 일반화 `R(k)` = 포아송 역산
- 표본간격 = PM / R0,  기본정밀도 = 표본간격 × R0
- 오염률 = (장부가 − 감사가) / 장부가,  추정왜곡 = 오염률 × 표본간격
- 상한오차(UEL) = 기본정밀도 + Σ(추정왜곡ⱼ × 증분계수ⱼ) + 고액항목 실차이
- **검증**: 산출 R값이 AICPA 표와 일치 (95%: 3.00 / 4.75 / 6.30 / 7.76, 증분 1.75 / 1.55 / 1.46)

### 알고리즘 출처
- 자체 **axon 결정론 MUS 엔진**(Rust `axon-core` / `axon-ledger`)의 표본추출 로직을 엑셀 VBA로 이식.
  → 데스크톱 도구와 동일한 결정론 알고리즘 계보.

### 참고 자료(웹)
- ISA 530 (IAASB) · ciferi ISA 530 MUS 예제 · Learn Audit Sampling (MUS extrapolation)

## 6. 한계 / 유의

- **난수 방식**: 엑셀 `Rnd`(시드 기반). 도구 내 재현은 보장되나, **IDEA/ACL 등 타 감사툴과 표본
  숫자가 동일하지는 않다**(난수 알고리즘이 다름).
- **기대오류**: 현재 0건 가정(가장 일반적). 기대오류 > 0 입력 옵션은 미포함.
- **평가 갱신**: `감사가` 수정 후 **`MUS 평가`를 다시 실행**해야 UEL/판정이 갱신됨(순위 정렬 때문에
  자동 셀 수식 불가).
- **실무 적용 전**: 소속 법인의 감사방법론·표본추출 정책 부합 여부 검토 권장.
