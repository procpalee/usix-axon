# axon MUS — 엑셀 매크로(.xlsm) 버전

설치 의존성 **0**. Rust·Node·인증서·사이드로드 전부 불필요 — **엑셀만** 있으면 된다.
`MUS.bas` 하나에 화폐단위표본추출(MUS/PPS) 알고리즘이 순수 VBA로 들어있다.

> Office.js 애드인 버전(`../excel-mus`)과 같은 감사 로직이다. 차이: 시작점 PRNG 가
> 데스크톱/WASM 의 splitmix64 가 아니라 VBA `Rnd`(시드 기반)이라, 두 도구의 표본이
> 서로 똑같지는 않다. 각 도구 안에서는 **같은 시드 = 같은 표본**으로 재현된다.

## 파일 안내 (권장 = 감사용)

- **`MUS_Audit.bas`** ⭐ **권장** — 순수 ASCII(로캘 무관). ISA 530 기반 감사용:
  실행 로그(`MUS_Log` 시트)·자기문서화 조서·오염률/추정왜곡·UEL/판정(라이브 수식)·
  `.xlam` 추가기능 버튼(Auto_Open) 포함. 영어 UI.
- `MUS_EN.bas` — 영어 전용 기본 버전(로그/평가 없음).
- `MUS_kr.bas` / `MUS.bas` — 한글 UI(CP949 / UTF-8). 국문 윈도우 로캘에서만 정상.

### .xlam(엑셀 추가 기능)으로 배포
1. `MUS_Audit.bas` 를 가져오거나 붙여넣는다(아래 설치 참고).
2. **다른 이름으로 저장 → 파일 형식: `Excel 추가 기능 (*.xlam)`**.
3. **개발 도구 → Excel 추가 기능 → 찾아보기** 로 저장한 `.xlam` 을 체크.
4. 이후 모든 엑셀 세션에서 자동 로드 — **추가 기능 탭**에 `MUS Sample` 버튼이 뜬다.

## 파일 안내 (인코딩)

- **`MUS_kr.bas`** — 한글 윈도우 엑셀용 **CP949** 인코딩. **국문 환경은 이 파일을 가져올 것.**
- `MUS.bas` — UTF-8 원본(저장소 정본). VBA 편집기는 가져오기 시 시스템 ANSI(국문=CP949)로
  읽어, UTF-8 그대로 가져오면 한글 주석/문자열이 깨진다. 그래서 국문 윈도우는 `MUS_kr.bas` 사용.

## 설치 (최초 1회, 2분)

1. 엑셀을 연다.
2. **`Alt + F11`** → VBA 편집기.
3. 메뉴 **파일 → 파일 가져오기(Import File)** → **`MUS_kr.bas`** 선택.
   (또는: **삽입 → 모듈** 후 `MUS.bas` 내용을 복사해 붙여넣기 — 붙여넣기는 인코딩 무관.)
4. `Alt + F11` 로 편집기를 닫는다.
5. **다른 이름으로 저장 → 파일 형식: `Excel 매크로 사용 통합 문서 (*.xlsm)`** 로 저장.

## 사용

1. 데이터를 시트에 둔다 — **맨 윗줄은 제목(헤더)**.
2. **`Alt + F8`** → `MUS_표본추출` → **실행**.
3. 묻는 대로 입력: 범위 → 금액열 번호 → PM → 신뢰수준(0.95) → 시드(42).
4. 새 시트(`MUS 95% s42`)에 표본이 나온다:
   - **Type**: `Key Item`(고액 = 전수검사) / `PPS Sample`(체계적 추출)
   - **Book_Value**(장부가) / **Audit_Value**(감사가 — 감사 후 직접 수정해 쓰는 칸)

### 버튼으로 만들기 (선택)
**개발 도구 탭 → 삽입 → 단추(양식 컨트롤)** → 시트에 그린 뒤 `MUS_표본추출` 매크로를 연결하면,
이후엔 버튼 클릭 한 번으로 실행된다. (개발 도구 탭이 안 보이면: 파일 → 옵션 → 리본 사용자 지정 → '개발 도구' 체크.)
